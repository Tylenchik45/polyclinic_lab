Лабораторная №1 по прикладному программированию. Тема: классы для предметной области поликлиники.

## Требования:
- Python 3.12 или выше (на нем написан проект) (проверить версию: 'python --version')
- Git (для клонирования репозитория)
- Установка сторонних модулей и библиотек не требуется, проект использует только стандартную библиотеку Python

## Структура проекта:
>polyclinic_lab
|->docs
| |->start_uml.svg (UML диаграмма)
| |->start_uml.txt (Текстовое описание UML диаграммы. https://plantuml.online/ использовал для написания)
| |->data_structure_template.json (Шаблон структуры с данными)
| |->data_structure_template.xml  (Сделан через https://jsonlint.vercel.app/json-to-xml)
|
|->exceptions
| |->custom_errors.py (классы исключений)
|
|->storage
| |->file_handler.py (работа с файлами)
|
|->structure
| |->classes.py (Описание всех классов)
| |->class_manager.py (Весь функционал для работы с классами)
|
|->main.py (Файл для запуска. Все тесты и проверки тут)
|
|->README.txt (Этот файл)
/

## Для запуска проекта:
/////////////////////
>git clone https://github.com/YourName/polyclinic-lab.git
>cd polyclinic_lab
>python main.py
////////////////////

## Запуск через PyCharm:
1. Откройте PyCharm -> File -> Open _> выберите папку проекта.
3. Откройте файл `main.py`.
4. Нажмите -> Run 'main' (или 'Shift + F10').
5. Результат работы будет выведен в консоль PyCharm.
